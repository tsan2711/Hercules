HERCULES CHESS BUILD - HƯỚNG DẪN NHANH

1. Tải gói build mới nhất (ví dụ Hercules_Build.zip)
2. Nhấp chuột phải vào file .zip và chọn "Extract All..." (không chạy file .exe trực tiếp trong zip).
3. Mở thư mục sau khi giải nén; bạn sẽ thấy file Hercules.exe
4. Nhấp đúp Hercules.exe để khởi chạy trò chơi.
   - Nếu Windows SmartScreen cảnh báo về nhà phát hành lạ, chọn "More info" → "Run anyway".
   - Build sử dụng DirectX; hãy đảm bảo driver GPU của bạn đã được cập nhật.
5. (Tuỳ chọn) Tạo shortcut cho Hercules.exe nếu muốn mở nhanh hơn.

KHẮC PHỤC SỰ CỐ
- Thiếu DLL hoặc lỗi VC++: cài đặt Microsoft Visual C++ Redistributable (x64) mới nhất.
- Game không chạy hoặc crash ngay: thử chạy bằng quyền Administrator hoặc bật chế độ tương thích Windows 10.
- Hiệu năng thấp: tắt bớt ứng dụng nền và đảm bảo bạn giải nén build vào ổ đĩa cục bộ (không phải mạng).
